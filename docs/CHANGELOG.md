# Changelog

所有用户可见变化记录在此。格式参考 Keep a Changelog 的分类思想，版本遵循 SemVer；未发布内容只放 `[Unreleased]`。

## [Unreleased]

### Added

- 新增开发者可运行的“知枝”知识树 Web Demo：三栏工作台、8 节点示例树、
  节点/笔记编辑、添加子概念、叶节点删除、拖动、自动排布、位置锁和会话内
  撤销/重做。
- 新增桌面与移动响应式布局、状态提示和明确的“示例数据 / 仅本次会话 /
  AI 未连接”能力边界。
- 新增本地持久化：编辑自动保存到本地 SQLite，关闭重开后内容仍在；底部
  状态栏显示“已保存到本地 / 保存中 / 保存失败 / 本地服务未连接”。
- 新增全文搜索：按概念标题或笔记内容搜索并点击定位节点。
- 新增安全导入：白名单类型（Markdown/TXT/PDF）、≤25 MiB、同名内容去重。
- 新增 PDF 查看：页文本阅读 + PDF.js 可视化渲染，锚点目录跳转与 bbox 区域
  高亮，内容漂移时明确提示不误跳。
- 新增人工编辑安全感（第 6 步已完成）：内容/位置锁定（锁定项在整图保存时
  不被覆盖，锁定维度修改返回 `target_locked`），撤销/重做在会话内无操作时
  回退到本地历史（跨会话撤销锁定操作）。
- 新增冲突预览与崩溃恢复：保存遇到锁定/版本冲突时给出具体提示；侧边栏可
  备份数据、从带校验和的本地备份一键恢复，数据损坏时明确提示。
- 新增版本历史面板：侧边栏展示每次已提交修改的版本号（vN→vN+1）与标识。
- 新增普通编辑的跨会话撤销：新增/修改/删除概念与边、拖动布局的每次保存都被
  自动 diff 成受保护的 GraphPatch 提交，所有编辑均可跨会话撤销/重做。
- 新增 Markdown/TXT 原文查看：导入的 Markdown/TXT 可在资料查看器中打开阅读原文。
- 新增 Markdown 富文本渲染：Markdown 笔记按标题/加粗/斜体/列表/代码块渲染（先
  转义 HTML，防注入）。
- 新增知识树画布平移与缩放：滚轮缩放、拖动空白平移、节点拖动按缩放换算。
- 新增真实 DeepSeek 接入（第 7 步，后端）：canonical LLM contract、OpenAI Chat
  Completions 协议适配器与 DeepSeek vendor profile、显式 thinking/流式/工具调用、
  错误映射与重试/熔断/预算，以及受控真实 smoke（文本/JSON/思考/工具/流式 5/5）。
  DeepSeek deployment 仍保持关闭，尚未接入产品界面。
- 新增 LLM 费用与降级保护（第 7 步收口）：金额预算（`max_cost_usd` + 每 token 定价
  快照）、受控回退（`ModelRunner` 仅瞬态错误回退）、HTTPS 强制、微积分金标基线
  （`EVAL-LLM-001`）与 `RB-PROV-001` 演练；隔离审查发现并修复全部 blocking。

### Changed

- 将旧工程状态页替换为可交互知识树工作台。
- 后端写入由“整图 PUT”扩展为“受保护的 GraphPatch 提交门 + 跨会话撤销/重做”：
  已确认修改经锁定/revision/确认门落盘，图与历史单事务原子，重复 change_id
  幂等拒绝，篡改历史失败关闭。

### Fixed

- 首次运行即锁定内容时缺少基础图导致锁定失败——已改为锁定前先同步当前快照。

### Security

- 锁定维度在存储边界强制（锁降级 / 锁定内容被改 / 锁定概念删除均被拒绝）；
  错误详情只含标识，不含笔记或来源正文。
- API 仅监听 loopback，CORS 白名单默认仅 Vite 开发地址；不访问网络、不调用
  LLM、不读取 API Key。
- LLM 真实调用仅在后端测试中受 `RUN_LIVE_LLM_TESTS=1` + `DEEPSEEK_API_KEY`
  双重门控，密钥只经环境变量进入、绝不落盘或提交；除 mock 外所有 provider
  保持 `enabled: false`。

> 正式发布条目还应包含发布日期、升级/迁移说明、已知问题和版本比较链接。
