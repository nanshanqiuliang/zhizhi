# 知识树笔记 App：自然语言开发路线

> 这份路线用于回答“现在做到哪一步、下一步在做什么”。它把工程术语转换成用户能直接理解的产品步骤；技术事实仍以 `ENGINEERING_PLAN.md`、工作项、提交和测试报告为准。

## 最终目标

做一个 Windows 本地优先的个人笔记 App：用户可以写笔记、导入资料，手工创建和编辑树状知识图；AI 可以从笔记和资料中生成带来源的知识树草案，但不能覆盖用户锁定的内容，所有重要修改都可预览、确认、撤销和追溯。

## 默认的首版边界

除非用户随后修改，开发按以下默认值推进：

- 单用户、Windows、本地优先；先交付浏览器中可见的 Web 界面，再封装桌面 App。
- 第一批资料格式为 Markdown/TXT/PDF；PPTX、DOCX、图片 OCR 在核心闭环稳定后加入。
- 先保证无 AI 也能正常写笔记和编辑知识树，再接真实 AI。
- AI 只生成草案；创建、删除、合并、批量重排等修改先预览再确认。
- DeepSeek 是第一个真实 LLM 适配目标；live gate 通过前只运行 mock/fixture。
- 人工编辑、位置、关系和重点标记可以分别锁定，AI 后续重建不能覆盖锁定项。

## 完整步骤

### 第 0 步：把开发地基搭好

通俗解释：先保证代码能安装、测试、回滚，准备一套可验证的微积分样本，并证明 AI 审核流程不会把假结果冒充产品结果。

完成标志：仓库、依赖锁、自动检查、基础网页壳、金标数据、离线 AI 审核原型和证据齐全。

当前状态：**已完成（100%）**。这一步主要是工程基础，用户目前只能看到工程状态页，还不是笔记 App。

### 第 1 步：把第一版到底做什么说清楚

通俗解释：明确第一版支持什么资料、数据放在哪里、哪些 AI 操作必须确认、什么叫“可以开始做产品”。

主要产物：首版范围和非目标、数据目录/备份/删除承诺、概念粒度、锁定规则、AI 默认权限、首批格式与验收清单。

完成标志：剩余产品问题有明确答案或安全默认值，后续开发不再因为范围反复返工。

当前状态：**开发默认值已完成（100%）**。十项首版问题及安全默认值已经写入 WORK-2026-002、PRD v0.3 和 ADR-0016，并经两轮独立 QA 收敛为 PASS；精确文档批准仍由 workspace owner 决定，不影响可回滚的离线底层开发。

### 第 2 步：规定笔记和知识树怎样保存、怎样修改

通俗解释：先定义“节点、连线、笔记、来源、位置、锁定”是什么，以及一次修改如何预览、校验和撤销。这样前端和 AI 都只能走同一套安全修改规则。

主要产物：Anchor v1、GraphPatch v1、节点/边类型、锁定语义、循环检测、修改校验和属性测试。

完成标志：无效连线、先修环、覆盖锁定内容等操作会被稳定拒绝；合法修改可以重放和撤销。

当前状态：**红灯测试已建立（约 10%）**。WORK-2026-005 已通过 Ready 门；第一批测试已按预期因契约/领域入口不存在而失败，下一步实现共同数据语言；尚未形成用户可见界面。

### 第 3 步：做出真正可操作的知识树网页

通俗解释：把当前工程状态页替换/扩展成像产品的三栏界面，能够看到树、拖节点、连线、创建和编辑节点。

主要产物：知识树画布、自动树状布局、节点详情、简单笔记编辑、创建/删除/连线/拖拽、示例数据。

完成标志：用户不用 AI，也能在浏览器完成一张小型知识树，并刷新后恢复演示数据。

当前状态：**尚未开始**。完成后将出现第一个“看起来像 App”的版本，连续推进预计约 1–2 周可见。

### 第 4 步：让笔记和知识树真正保存在本地

通俗解释：把演示页面变成可持续使用的个人工作区，而不是刷新就丢的 Demo。

主要产物：本地工作区、课程/主题、笔记、SQLite 存储、自动保存、基础搜索、导入导出和备份入口。

完成标志：关闭并重新打开后内容仍在；数据可导出、备份和恢复。

当前状态：**尚未开始**。

### 第 5 步：导入资料，并能从节点点回原文

通俗解释：把 Markdown/TXT/PDF 导入 App；节点不仅是一张卡片，还能告诉用户依据来自哪份资料、哪一页或哪一段。

主要产物：安全文件导入、解析任务进度、PDF/文本查看器、来源列表、页码/文本定位和高亮。

完成标志：点击节点可稳定打开正确资料位置；找不到或资料漂移时明确提示，不误跳。

当前状态：**产品实现尚未开始**；微积分 PDF 金标和页级样本已经准备好，可直接用于验收。

### 第 6 步：补齐人工编辑所需的安全感

通俗解释：让用户敢于长期使用——改错能撤销，重要内容能锁定，AI 或重新导入不会破坏人工成果。

主要产物：版本历史、撤销/重做、节点/关系/位置分别锁定、冲突预览、崩溃恢复和重复任务保护。

完成标志：重建知识树时锁定项误改为 0；失败或重启不会重复写入。

当前状态：**尚未开始**。完成第 3–6 步后，形成“不依赖 AI 也能使用”的手工 Alpha。

### 第 7 步：安全接入第一个真实 AI

通俗解释：让 App 真正连接 DeepSeek，但先只做受控调用，不直接修改用户数据。

主要产物：统一模型接口、DeepSeek adapter、结构化输出、流式响应、超时/重试/预算、密钥安全和真实 smoke test。

完成标志：真实模型能稳定返回符合契约的草案；失败可定位、费用可控、日志不泄露内容或密钥。

当前状态：**只有静态配置和离线审核基础，真实适配尚未实现**。

### 第 8 步：让 AI 从笔记和资料自动生成知识树草案

通俗解释：AI 读取用户授权的笔记/资料，抽取概念、去重、推断树状关系，并把结果作为可审核草案显示出来。

主要产物：文档分块、概念抽取、别名合并、关系候选、置信度、DAG 校验、自动布局、批量接受/拒绝和修改理由。

完成标志：用户能导入一组微积分资料，看到“极限 → 连续 → 导数……”草案；每个节点/关系带来源，确认后才写入。

当前状态：**尚未开始产品实现**；30/40/50 金标集和离线 AI QA harness 已完成，可作为质量门。

### 第 9 步：加入对话、检索和持续整理

通俗解释：用户可以用自然语言要求“把可导与连续标为重点”“解释这条关系”“根据新笔记补充树”，AI 给出带引用的修改预览或回答。

主要产物：本地全文/向量检索、带来源问答、自然语言转 GraphPatch、增量重建、AI 修改历史。

完成标志：对话产生的图修改可预览、确认、撤销；回答能点回来源；人工锁定始终优先。

当前状态：**尚未开始**。

### 第 10 步：封装为 Windows App，并完成个人 MVP 验收

通俗解释：把网页、Python 后端和本地数据组合成能安装、启动、升级和备份的桌面应用。

主要产物：Tauri 桌面壳、本地 sidecar 生命周期、路径权限、安装包、迁移/备份/恢复、端到端测试和用户说明。

完成标志：新机器可安装；从写笔记/导入资料到人工编辑、AI 草案、来源回跳、撤销恢复的完整流程通过。

当前状态：**尚未开始**。完成第 0–10 步即达到“个人可用 MVP”。按 Proposal 的原始估算，持续开发约需 8–12 周；当前整体仍处早期。

### 第 11 步：Beta 加固与扩展

通俗解释：在个人 MVP 可用后，再增加联网资料、多格式、性能、安全和公开测试能力。

主要产物：受控 Web Search、PPTX/DOCX/OCR、更多模型、失效链接巡检、大图性能、安全红队、诊断、签名更新和导入导出扩展。

完成标志：达到可公开测试 Beta 的稳定性与安全门槛。

当前状态：**尚未开始**。Proposal 原始估算为项目启动后约 16–24 周，不计需求大改或外部服务阻塞。

## 用户说“继续推进”时的固定工作方式

收到“继续推进”“继续开发”“往下做”等指令后，默认执行以下规则：

1. 读取本路线、`checkpoint.md`、工程计划和当前工作项，找出最后一个可靠完成点。
2. 不跳过尚未通过的核心门；从当前自然语言步骤里选择最小的下一项实际实现。
3. 开始时简短报告：当前步骤、本步进度、MVP 粗略进度、本轮准备完成的内容。
4. 直接开发、测试并保存证据，不只输出计划。
5. 结束时报告：仍处第几步、本轮从多少推进到多少、完成了什么、验证结果、下一动作和是否需要用户决定。
6. 每完成重要阶段，更新本文件和 `checkpoint.md`，防止上下文压缩或网络中断后丢失进度。

固定输出格式：

```text
当前步骤：第 N 步——<自然语言名称>
本步进度：约 X% → Y%
MVP 总进度：约 A% → B%
本轮完成：<用户能理解的成果>
验证结果：<测试/构建/可见结果>
下一动作：<下一件实际工作>
用户待决定：无 / <真正会改变方向的问题>
```

进度百分比只用于沟通方向：必须由已提交的功能和可重复验证支撑；计划、文档数量和测试数量本身不算产品功能完成度。
