# 用户手册

> status: developer_demo
> 当前没有安装包，也不是可长期保存数据的个人 MVP。开发者现在可以运行一个
> 会话内知识树 Web Demo；页面会明确标出尚未接入的能力。

## 当前可以做什么

- 查看包含 8 个概念的“微积分 · 连续性与可导性”示例知识树；
- 点击树节点，在右侧编辑概念标题和笔记；
- 给当前节点添加子概念，删除没有子节点的概念；
- 拖动节点，自动排布知识树，并锁定某个节点的位置；
- 在当前浏览器会话中撤销和重做修改；
- 一键重新载入初始示例。

## 如何运行

前置条件：Windows 开发环境已经按仓库根 README 完成锁定依赖安装。

```powershell
pnpm --filter @knowledge-tree/web dev
```

打开命令输出的本地地址。看到“知枝”“示例数据”和 8 个树节点即表示启动成功。

## 基本操作

1. 点击画布中的概念节点；右侧“节点详情”会显示它的标题和笔记。
2. 修改标题或笔记后点击“保存修改”。
3. 点击“添加子概念”会在当前节点下创建“新概念”，并自动选中它。
4. “删除当前节点”只允许删除叶节点。如果节点还有子节点，底部状态栏会提示
   “只能删除没有子节点的概念”，并保留原数据。
5. 在画布中拖动节点可改变位置；“锁定位置”后执行“自动排布”，该节点保持原位。
6. 顶部“撤销/重做”只作用于当前页面会话；“重新载入示例”清空历史并恢复 8 个初始节点。

## 数据、联网和隐私边界

- 所有内容都是仓库内自写示例，不读取真实用户文件。
- 修改只存在 React 内存中，不写浏览器存储、文件或数据库；刷新/关闭页面会丢失修改。
- 当前不访问网络，不调用 DeepSeek 或其他 LLM，不读取 API Key。
- “AI 未连接”表示自动构图尚未实现；当前树完全由人工操作。
- 来源跳转、Markdown/TXT/PDF 导入、本地搜索、备份/恢复和 Windows 安装包尚不可用。

## 失败与恢复

- 标题为空时不会保存，底部状态栏显示“概念标题不能为空”。
- 非叶节点不会被级联删除；先处理它的子节点，或使用“撤销/重做”恢复修改。
- 布局混乱时可点击“自动排布”；需要彻底恢复时点击“重新载入示例”。
- 页面刷新会恢复示例，这不是数据恢复功能。请勿在当前 Demo 中录入需要保留的真实内容。

## 当前验证范围

无障碍名称。浏览器已在 1440×900 与 390×844 下检查；移动端把画布横向滚动
限制在画布内部，不产生整页横向溢出。
