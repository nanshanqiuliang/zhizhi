# 用户手册

> status: local_prototype
> 提供两种运行方式：① **便携桌面 exe**（见下方「桌面打包版」，解压即用，无需 Python/Node）；
> ② 源码运行（需同时启动本地 API 与 Web 页面）。
> 数据目录、备份/恢复、撤销/锁定、导入/PDF/AI 草案等能力在两种方式下一致。
> 本手册按当前已验证功能编写；AI 能力需设置 `DEEPSEEK_API_KEY` 环境变量（无 key 时安全显示「AI 未连接」）。

## 桌面打包版（便携 exe，第 10 步切片 1）

不用装 Python/Node，也不用开两个终端：构建后得到一个便携目录，解压即用。

**构建**（开发者，仓库根目录；需先 `uv sync --group dev --group build` 与
`pnpm install --frozen-lockfile`）：

```powershell
pnpm --filter @knowledge-tree/web build
uv run python scripts/build_desktop.py
```

产物：`dist\zhizhi\`（含 `zhizhi.exe` 与 `_internal\`）。

**使用**（任意 Windows 10/11 机器）：

1. 把整个 `dist\zhizhi\` 目录复制/解压到任意位置（例如 `D:\apps\zhizhi\`）。
2. 双击 `zhizhi.exe`（或命令行 `zhizhi.exe --data-root <目录> --port <端口>`）。
3. 看到控制台输出「知枝 已启动：http://127.0.0.1:8000/」，默认浏览器自动打开界面。
4. 关闭：在控制台按 Ctrl+C（或关掉控制台窗口）。

说明：

- 数据目录默认 `%LOCALAPPDATA%\知枝\data`（即 `C:\Users\<你>\AppData\Local\知枝\data`）；
  升级/替换 `zhizhi\` 目录不会丢失数据；可用 `--data-root` 改到别处（含旧的
  `knowledge-tree-data`）。
- 单实例：已有一个实例在运行时会自动退出，不会双写数据或抢端口。
- AI 功能（草案/问答/指令）：设一次环境变量 `DEEPSEEK_API_KEY` 后启动，无 key 时界面安全
  显示「AI 未连接」。
- 备份/恢复、撤销/重做、锁定、来源回跳等能力与源码运行完全一致。
- 尚未实现：原生窗口壳（当前用系统浏览器）与安装器（Inno Setup）——待后续切片。

## 当前可以做什么

- 查看并人工编辑"微积分 · 连续性与可导性"知识树（8 个示例概念）；
- 点击节点编辑标题/笔记，添加子概念、删除叶节点、拖动、自动排布、锁定位置；
- 画布平移与缩放：滚轮缩放（0.5×–2.5×）、拖动空白区域平移、拖动节点调整位置。
- 会话内撤销/重做与一键重载示例；
- **本地持久化**：修改会自动保存到本地 SQLite，关闭并重新打开页面后内容仍在；
- **保存状态可见**：底部状态栏显示"已保存到本地/保存中/保存失败"；本地 API
  未启动时显示"本地服务未连接"；
- **全文搜索**：按概念标题或笔记内容搜索并点击定位节点；
- **安全导入**：把本地 Markdown/TXT/PDF 导入工作区（白名单类型、≤25 MiB、
  同名内容自动去重）；
- **PDF 查看**：已导入的 PDF 可解析为页文本阅读，也可切换"渲染"用 PDF.js
  显示页面原貌；
- **锚点跳转与高亮**：锚点目录点击后跳到对应页；带区域（bbox）的锚点在
  渲染视图中高亮原文位置；
- **Markdown/TXT 查看**：导入的 Markdown/TXT 资料点"打开"在查看器中阅读原文；
  Markdown 按标题/加粗/斜体/列表/代码块富文本渲染（先转义 HTML，防注入），TXT 为纯文本。
- **内容漂移保护**：资料被替换/变化时明确提示"资料已变化，无法定位"，
  不跳到错误位置。
- **内容/位置锁定**：节点详情面板可"锁定内容"/"锁定位置"，锁定项在保存时
  不被覆盖（被锁定的标题/位置若被整体保存修改会返回"该维度已锁定"）；
  节点卡片显示锁标记。
- **撤销/重做**：会话内编辑可撤销/重做；当会话内无操作时，撤销按钮回退到
  本地持久历史。所有编辑（新增/修改/删除概念与边、拖动布局）的保存都会
  自动记录为一步历史，关闭重开后仍可跨会话撤销/重做。
- **冲突预览**：保存遇到锁定/版本冲突时明确提示原因（"该内容已锁定"/"版本冲突"），
  而不是笼统的"保存失败"。
- **本地备份/恢复**：侧边栏可"备份数据"；当本地数据损坏时提示"从备份恢复"，
  可从备份列表一键恢复。
- **AI 状态**：界面当前不接 AI；DeepSeek 后端 adapter 已经 owner 批准启用（`enabled: true`），
  但 AI 自动构图/对话属第 8 步，尚未接入产品界面。

## 如何运行（人工验证）

前置条件：仓库根目录已按 README 完成锁定依赖安装（`uv sync --locked --group dev`
与 `pnpm install --frozen-lockfile`）。

需要两个终端：

**终端 1 — 启动本地 API**（推荐把数据目录放到仓库之外，例如
`C:\Users\<你>\knowledge-tree-data`）：

```powershell
uv run python -m apps.api --data-root C:\Users\<你>\knowledge-tree-data
```

看到 `Uvicorn running on http://127.0.0.1:8000` 即成功。默认端口 8000；
若端口被占用可用 `--port 8127`，但随后需给 Web 指定同一地址（见下）。

**终端 2 — 启动 Web**：

```powershell
pnpm --filter @knowledge-tree/web dev
```

打开命令输出的地址（默认 `http://localhost:5173/`）。看到"知枝"、顶部搜索框、
左侧"本地资料"区域即表示 Web 已连上本地 API（状态栏应显示"已连接本地数据库"）。

> 若 API 用了非默认端口，Web 启动时需指定：
> `$env:VITE_LOCAL_API="http://127.0.0.1:8127"; pnpm --filter @knowledge-tree/web dev`

## 人工验收清单

按顺序验证，每项给出预期结果。

### 1. 持久化与重启存活
1. 编辑任意节点标题/笔记，点击"保存修改"；状态栏出现"已保存到本地"。
2. **关闭浏览器页面，重新打开** `http://localhost:5173/`。
3. 预期：修改后的内容仍在（不再是示例初始值）。
4. 停止 API（终端 1 Ctrl+C）后刷新页面 → 状态栏显示"本地服务未连接"，
   且**不清空**当前编辑内容；重新启动 API 后再刷新即恢复。

### 2. 全文搜索
1. 在顶部搜索框输入"极限"。
2. 预期：下拉列出匹配概念（如"极限"），点击"定位到概念：极限"后画布选中该节点。

### 3. 资料导入与去重
1. 在左侧"本地资料"点击"导入资料（MD / TXT / PDF）"，选一个 `.md` 或 `.txt` 文件。
2. 预期：列表出现该文件名（含类型与大小）。
3. 再次导入同一文件 → 预期不产生重复条目（同内容去重）。
4. 尝试导入 `.exe` 等非白名单类型 → 预期提示"导入失败，请检查文件类型与大小"。

### 4. PDF 页文本查看
1. 导入一份 PDF（可用 `evals\calculus-v1\source\mit-ocw-res-18-001-chapter-02-derivatives.pdf`）。
2. 列表该项点"打开"→ 查看器出现，默认显示第 1 页文本（含 "CHAPTER 2 / Derivatives"）。
3. 点"下一页 →" → 显示第 2 页；"第 N 页"计数正确。

### 5. PDF.js 渲染与高亮
1. 查看器中点"渲染"。
2. 预期：出现页面图像（canvas），不再是纯文本。
3. 若有锚点目录（需要先通过 API 注册锚点，见下），点某锚点 → 跳到对应页；
   带 bbox 的锚点会在页面上显示橙色高亮框，位置与内容对齐（可缩放窗口宽度验证
   高亮不漂移）。

### 6. 锚点注册与漂移保护（可选，需命令行）
```powershell
# 注册一个第 3 页的 bbox 锚点（替换 <resource-id> 为导入 PDF 的 id）
uv run python -c "import json,urllib.request; u='http://127.0.0.1:8000/api/workspaces/00000000-0000-7000-8000-000000000001/resources/<resource-id>/anchors'; d=json.dumps({'page':3,'payload':{'topic_zh':'导数定义','bbox_norm':[0.1,0.2,0.6,0.35]}}).encode(); r=urllib.request.Request(u,data=d,headers={'Content-Type':'application/json'},method='POST'); print(urllib.request.urlopen(r).read().decode())"
```
刷新 Web 后打开该 PDF → 锚点目录出现"导数定义"→ 点击 → 跳到第 3 页并显示高亮框。
（替换 `<resource-id>` 后再替换文件内容，Web 端应提示"资料已变化，无法定位"。）

### 7. 锁定与撤销
1. 点击"极限"节点，点详情面板"锁定内容"。
2. 预期：节点卡片出现"锁"标记；状态栏提示已锁定内容。
3. 修改该节点标题并点"保存修改" → 预期状态栏提示锁定失败（该维度已锁定，
   标题保持不变）。
4. 点工具栏"撤销" → 预期锁定解除、"锁"标记消失（若会话内无其他可撤销操作，
   则回退到本地持久历史撤销本次锁定）。

## 数据、联网和隐私边界

- 数据目录（`--data-root`）内是本应用唯一读写位置：`knowledge-tree.db`、
  `resources/`（导入文件副本）、`backups/`、`exports/`。仓库本身不写入用户内容。
- API 只监听 `127.0.0.1`（loopback），CORS 白名单默认仅 Vite 开发地址；
  Web 渲染 PDF 在浏览器本地执行，不上传任何文件。
- 当前不访问网络，不调用 DeepSeek 或其他 LLM，不读取 API Key。
- "AI 未连接"表示自动构图尚未实现；树完全由人工操作。
- 尚未实现：Windows 安装器/原生窗口壳（当前为便携 exe + 系统浏览器）、系统托盘/文件关联、
  OCR、中文分词、多页连续滚动渲染、云同步、向量检索（Embedding provider 未决）。

## 失败与恢复

- 保存失败：状态栏显示"保存失败"，编辑内容保留在页面，可继续修改后重试。
- 锁定项被改：整图保存试图覆盖锁定维度时被拒（"该维度已锁定，无法修改"），
  解锁或保留原内容后重试。
- 版本冲突：提示"保存被拒：版本冲突，请刷新后重试"；刷新页面后重做修改。
- 本地数据损坏：提示"本地数据损坏，请从备份恢复"；侧边栏选择备份一键恢复。
- 本地服务未连接：API 未启动或已退出；启动 API 后刷新页面恢复。
- 资料漂移：提示"资料已变化，无法定位"，不会跳到错误位置。
- 标题为空不保存；非叶节点不会被级联删除。
- 布局混乱：点"自动排布"；需要彻底恢复示例：点"重新载入示例"（这会保存示例
  覆盖当前图，请确认不需要保留当前内容）。
- 数据备份：侧边栏点"备份数据"生成带校验和的 SQLite 备份；恢复从备份列表选择。
