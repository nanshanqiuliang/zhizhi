## 问题与结果

- 用户/工程问题：AI 自动绘制的思维导图**排布不均**——根窄下宽、父节点不对齐子节点
  中心、间距过小（x 220/y 140）观感紧凑，无先修关系的概念全挤顶行；Web「自动
  排布」更严重：`layoutWorkspace` 是**硬编码示例坐标**（course/limit/continuity/
  derivative），AI 大图点排布后未硬编码节点全挤 y=405 一行。
- 期望结果：布局**以上下排布为主**（父在上、子在下，垂直树形）且**均匀不紧凑**：
  ① 父节点水平居中于其子节点块上方；② 同父相邻子节点间距 ≥ x_gap；③ 间距默认
  放宽（domain x_gap 220→260、y_gap 140→210；Web 240/190）；④ 无层级关系的
  节点收到底行而不是挤顶行；⑤ Web「自动排布」改为**通用**垂直树形算法（任意
  图、锁定节点保持原位且作为子树切断点、环安全、孤立节点底行），不再硬编码。
- 成功如何被观察：红灯用例断言父居中/垂直间距/均匀展开/底行/确定性，绿灯后
  既有测试（拓扑分层、锁定保持、示例重载）不破坏；全门禁 + CI 绿。

## 范围

- In scope：
  - `packages/domain/.../ai_draft.py`：重写 `assign_draft_layout`——保留最长链
    拓扑分层；布局父取最深先修父（DAG 安全，多父节点只挂一处）；子树宽度递归
    铺开 + 父居中；无任何先修边的概念归**底行**；默认 `x_gap=260, y_gap=210`。
  - `apps/web/src/App.tsx`：重写 `layoutWorkspace`——通用垂直树形（任意边入向
    第一个父为布局父，与 `parentOf` 语义一致）；锁定节点保持原位且其子节点升为
    新子树根；BFS visited 防环；孤立节点底行；整体左上归一（40/44）；间距
    240/190。
  - 测试：`tests/unit/test_draft_layout_tree.py`（domain 性质断言）+ 
    `apps/web/src/App.layout2.test.tsx`（通用排布/居中/底行/锁定）。
- Out of scope：PNG 导出布局（`png_export.layout_tree` 已满足上下排布，不动）；
  水平/径向布局模式与主题；既有图自动重排（只影响新草案与用户主动点排布）；
  Web 端锁定节点子树的重心微调。
- 受影响模块/接口/数据：仅布局计算；`assign_draft_layout` 签名不变（默认参数值

  环由 visited 防护。

## 风险影响

- 数据/schema/migration：无。
- 兼容性：自动排布对示例图产生的新坐标与旧硬编码不同（示例观感不变仍为三层
  树形）；锁定节点行为不变；既有测试仅断言拓扑/锁定性质，兼容。
- 性能：节点数 ≤ 数百，递归布局毫秒级。
- 回滚：回退提交即回旧布局。

- [ ] AC-5：Web 自动排布对任意自定义图生效：子块低于并居中于父、孤立节点
  底行、锁定节点保持原位。
